# HCAHPS-Hospital.csv (Not Included)

This file is a placeholder for the large HCAHPS-Hospital data file used in this project.

The dataset used in this project is too large to upload to GitHub (105.5 MB) and is not publicly redistributed here.

To retrieve the dataset:
1. Visit https://data.cms.gov/provider-data/topics/hospitals
2. Download the "Patient survey (HCAHPS) - Hospital" dataset.
3. Place the CSV in this folder.
